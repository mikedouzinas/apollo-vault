# Professional Development

## Structure

```
Professional Development/
├── [Job or Program]/   — One folder per role, internship, or program you're in. Notes, reviews,
│                          decisions, whatever accumulates while you're in it.
├── Skills.md           — What you're building and how, updated as it changes rather than
│                          rewritten from scratch.
└── Search.md           — If you're between roles: what you're looking for, where you've applied,
                            what you learned from each conversation.
```

People you work with belong in `02_Areas/Relationships/`, not duplicated here — cross-reference rather than forking the file.

## What Goes Where

| Content | Location |
|---|---|
| Notes, decisions, or reviews tied to a specific role | `[Job or Program]/` |
| A skill you're actively building | `Skills.md` |
| Where you're looking, applications, what you learned from each conversation | `Search.md` |
| A colleague as a person | `02_Areas/Relationships/` |

## When a role ends

Move its folder to `04_Archive/` rather than deleting it. What you learned in a role you left is still true.
