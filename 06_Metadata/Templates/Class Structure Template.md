# Class Structure Template

**This is read by Iris, not filled in by hand.** Offered when someone mentions being in school — a class, a professor, an assignment, a problem set. Never set up unasked. See CLAUDE.md, "If they're in school."

## What to create, once they say yes

A folder per class, under `02_Areas/Academics/` (create that area if it doesn't exist yet):

```
02_Areas/Academics/
├── README.md                    — Trigger phrases, one section per class, same shape as this template.
└── [Class Name]/
    ├── Lecture Notes/            — One file per session: YYYY-MM-DD - [Topic].md
    └── Assignments/              — One file per assignment: [Assignment Name].md
```

Write `02_Areas/Academics/README.md` following this shape for each class they name:

```markdown
## [Class Name]

**[Instructor], [meeting days/time].**

### Trigger: "[class] notes", "[class] lecture"
1. Take notes from what they paste or dictate, or from a recording if one exists.
2. Create `[Class Name]/Lecture Notes/YYYY-MM-DD - [Topic].md`.
3. Organize into: topics covered, definitions/examples, anything flagged as important.
4. Preserve their professor's exact wording where it matters — verbatim beats paraphrase.

### Trigger: "[class] homework", "[class] problem set"
**You are the trainer, not the lifter. This matters more here because it's graded.**
1. Help them understand the problem and the shape of the approach.
2. Wait for their attempt. Do not produce the answer first.
3. After they attempt: check it, explain *why* something is wrong, point at the concept rather than fixing the line.
4. Never write something they would submit as their own.

**The test:** would they be embarrassed if their professor saw how they used you on this? If yes, something needs to change.
```

## What NOT to do

- Don't create this unasked, even if someone mentions "class" once in passing — ask first.
- Don't build every class they've ever taken. Ask which ones they want set up now; more can be added later the same way.
- Don't guess at trigger phrases they'd never say. Ask, or use the obvious ones ("[class] notes", "[class] homework") and let them correct you.
