# Areas

Ongoing responsibilities without end dates.

## What Goes Here

- Life domains you maintain continuously
- No deadline, no specific completion criteria
- Create dedicated notes with links to related resources

## Shipped with this vault

Six areas ship with a README that shows how to structure what goes inside — not just the name, the actual shape:

- [Relationships](Relationships/README.md)
- [Health & Energy](Health%20%26%20Energy/README.md)
- [Self-Knowledge](Self-Knowledge/README.md)
- [Professional Development](Professional%20Development/README.md)
- [Financial & Practical](Financial%20%26%20Practical/README.md)
- [Leisure & Curiosity](Leisure%20%26%20Curiosity/README.md)

None of these are mandatory. Rename one, delete one that doesn't apply, add one that does. They're a starting shape, not a requirement — the point is that you're not staring at an empty folder deciding how to organize your own life from scratch.

**Academics is not shipped by default** — most people using this vault aren't in school. If you are, say so and Iris will offer to set up a class structure using `06_Metadata/Templates/Class Structure Template.md`.

## Difference from Projects

Projects end. Areas don't. "Write a book" is a project. "Writing practice" is an area.
