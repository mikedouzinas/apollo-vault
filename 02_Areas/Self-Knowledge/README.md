# Self-Knowledge

## Structure

```
Self-Knowledge/
├── Core Convictions.md   — What you actually believe, revised as you learn more about yourself.
│                            Not aspirational. What's actually true right now.
├── Self-Observations/     — Dated notes on patterns you're noticing in how you think, decide, avoid.
└── [Framework Name]/      — If you build or adopt a way of thinking about yourself that grows past
                              one file, it gets its own folder.
```

## What Goes Where

| Content | Location |
|---|---|
| A belief you actually hold, not one you're supposed to | `Core Convictions.md` |
| A pattern you're noticing about how you operate | `Self-Observations/[Pattern].md` |
| A framework, model, or lens you're developing | `[Framework Name]/` |

## Why this area exists on its own

Patterns about yourself show up across every other area — relationships, work, health — but they belong here, not duplicated in each. When you notice the same avoidance in two different areas, that connection is only visible if both point back to one place.
