# Leisure & Curiosity

## Structure

```
Leisure & Curiosity/
├── Deep Work Queue.md   — Ideas and questions worth real, uninterrupted time when you have it: a
│                           long-form piece, a thing you want to build, a question you want to
│                           actually think through. Filed with enough context that you can pick it
│                           back up cold, months later.
└── [Interest].md        — One file per ongoing hobby or interest, wherever it's more than a passing
                            mention.
```

## What Goes Where

| Content | Location |
|---|---|
| Something you'd want to think about for a few uninterrupted hours, when you have them | `Deep Work Queue.md` |
| A hobby or interest you keep coming back to | `[Interest].md` |

## Why a queue instead of a to-do list

Deep-work ideas rot if they only live in a conversation that ends. The queue exists so that when you finally get a free afternoon, you have somewhere to look instead of starting from a blank page. When one comes up in conversation, offer to file it there with enough context to pick up cold — the trigger, the actual question, and anything you already have a gut sense about.
