# Financial & Practical

## Structure

```
Financial & Practical/
├── Budget.md              — The current picture: what's coming in, what's going out, what you're
│                             saving toward. Updated in place, not re-created each month.
└── [Recurring Thing]/     — Anything with no end date that still needs tracking: housing, insurance,
                              a vehicle, a subscription worth watching.
```

This is the area most likely to just be a couple of files for a while. That's fine — don't force structure that isn't earning its keep yet.

## What Goes Where

| Content | Location |
|---|---|
| Overall financial picture | `Budget.md` |
| A specific recurring practical thing (lease, insurance, etc.) | `[Thing].md` or `[Thing]/` once it has more than one file |
| A one-time financial decision (a purchase, a big move) | `01_Projects/` — it has an end, so it's a project, not an area |
