# Relationships

## Structure

**Person folders** (for relationships with enough going on that one file gets crowded):
```
Person Name/
├── Person Name.md       — Who they are. Facts, how they communicate, quotes worth keeping.
├── Timeline.md          — Chronological events. Add new entries at the bottom.
├── Plans.md             — Upcoming plans, logistics, things to follow up on.
└── Patterns & Growth.md — What you're noticing, specific to this relationship.
```

**When to create a folder:** when there's enough to say that a single file gets crowded. Someone you text occasionally is fine as a single file. Someone you see regularly, are building something with, or are actively working through something with — folder.

**Standalone files** (patterns that aren't about one person):
- `Patterns.md` — what you notice about yourself across relationships, not tied to any one person
- Group maps, if useful — `Family.md`, `Friends.md`, a team you're part of

## What Goes Where

| Content | Location |
|---|---|
| Facts about a person | `Person/Person.md` |
| What happened and when | `Person/Timeline.md` |
| Upcoming plans, logistics | `Person/Plans.md` |
| What you're noticing about this specific relationship | `Person/Patterns & Growth.md` |
| Patterns about yourself, not person-specific | `Patterns.md` |
